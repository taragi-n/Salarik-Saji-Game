# Salarik Saji

> **"Play your cards right, or face the wrath of the restless spirits."**
> 
> Game perdana dari **Sandekarya Studio** — Sebuah *Indonesian ritual-based horror card game*.

---

## About The Game
**Salarik Saji** adalah game horor berbasis kartu yang mengangkat atmosfer ritual mistis khas Indonesia. Dalam game ini, setiap kartu yang diisi atau ditarik menentukan nasibmu. Pemain ditantang untuk bertahan hidup di tengah ritual sakral yang tak kunjung usai, namun berhati-hatilah: para makhluk halus tidak pernah sabar. Satu kesalahan kecil saja dapat mengubah upacara ini menjadi mimpi buruk yang mengerikan.

 **Mainkan secara gratis di itch.io:**  
[Sandekarya Studio on itch.io](https://sandekaryastudio.itch.io/salarik-saji)

---

##  Key Features
- **Ritual-Based Card Mechanics:** Game horor dengan mekanik permainan kartu berbasis sesajen/ritual.
- **Atmospheric Indonesian Horror:** Suasana dan visual horor lokal Indonesia yang kental.
- **Endless Survival Mode:** Uji fokus dan ketenanganmu dalam menghadapi amarah para arwah.
- **Cross-Platform:** Didesain untuk dijalankan di Windows & Android.

---

##  Tech Stack & Tools
- **Engine:** Godot Engine 2D
- **Language:** GDScript
- **Art & Visuals:** Custom 2D Assets / Pixel Art
- **Audio & BGM:** FL Studio (Atmospheric Horror Soundscape)

---

##  How to Run Locally

### Prerequisites
- Godot Engine (versi 4.3 disarankan)

### Steps
1. Clone repositori ini:
   git clone [https://github.com/taragi-n/salarik-saji.git](https://github.com/taragi-n/salarik-saji.git)
2. Buka **Godot Engine**.
3. Klik tombol **Import**, lalu pilih file `project.godot` dari folder repositori.
4. Tekan **F5** (atau klik ikon **Play** di kanan atas) untuk mulai menjalankan game.
